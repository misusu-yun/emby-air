emby-air Docker 测试版

扫描 STRM、TMDB 刮削、Web 管理、兼容常见 Emby 客户端

本项目包含 AI 辅助生成/修改的代码和文档，可能存在错误或安全风险；使用前请自行审查和测试。详见仓库中的 AI-DISCLOSURE.md。

1. 准备条件

  • 一台安装了 Docker Engine 或 Docker Desktop 的机器；
  • Docker Compose v2（使用 docker compose 命令）；
  • 一个媒体目录，里面可以是 .strm 文件或视频文件；
  • 可选：TMDB API Key，用于自动获取简介、海报和分集信息。
第一次启动必须先设置一个管理员密码。不要把默认密码直接暴露到公网。

2. 目录结构

解压后应该是这样的结构：

emby-air-docker/
├── Dockerfile
├── docker-compose.yml
├── .env.example
├── README.md
├── 使用教程.html
└── app/
    ├── go.mod
    ├── go.sum
    ├── cmd/
    └── internal/

不需要安装 Go，Docker 会在构建镜像时编译源码。

3. 创建配置文件

在项目根目录执行：

cp .env.example .env

然后编辑 .env。至少需要改这几项：

配置项说明
MEDIA_PATH宿主机上的媒体目录，例如 /mnt/media 或 D:\Media
DATA_PATH数据库和缓存目录，默认 ./data，不要放在临时目录
ADMIN_PASSWORD首次启动的管理员密码，请设置一个强密码
TMDB_API_KEY可留空，启动后到 Web「设置」里填写也可以

示例：

MEDIA_PATH=/mnt/media
DATA_PATH=./data
ADMIN_USER=admin
ADMIN_PASSWORD=换成一个强密码
TMDB_API_KEY=
TZ=Asia/Shanghai
.env 里可能包含密码和 API Key，不要提交到 Git，也不要直接发给别人。

4. 启动

1
构建并启动容器：
docker compose up -d --build
2
查看启动日志：
docker compose logs -f --tail=100
3
看到类似 HTTP 服务已监听 :8098 即启动成功。
4
打开浏览器：
http://宿主机IP:8098/webui

如果就在本机测试，可以使用 http://127.0.0.1:8098/webui。

5. 在 Web 里添加媒体库

  1. 登录 Web 管理端；
  2. 进入「媒体库」；
  3. 填写名称，选择类型（电影 / 剧集）；
  4. 选择容器内路径。容器里的媒体根目录固定是 /media；
  5. 创建后点击扫描，或在任务中心查看扫描进度。
宿主机目录通过 MEDIA_PATH:/media 挂载。Web 里选择的是容器内路径，例如 /media/电影，不是宿主机的绝对路径。

6. Web 设置页

登录后进入「设置」，可以直接修改以下内容，不需要重建容器：

设置说明
TMDB API Key保存后不会回显；留空表示不修改，勾选清除可删除
TMDB 语言例如 zh-CN、en-US
HTTP/HTTPS 代理例如 http://proxy-host:7890；留空表示不使用
NO_PROXY不走代理的地址，例如 localhost,127.0.0.1
刮削速率1–15 req/s，建议 8–15
扫描后自动刮削扫描完成后自动补 TMDB 元数据
写 NFO把元数据写入 NFO 文件；要求媒体目录可写

生效规则：保存后新任务立即使用新配置；正在运行的任务继续使用旧配置。

设置保存在 data/emby.db，容器重启或重建后仍然保留。环境变量只作为首次启动的默认值。

7. 用 Emby 客户端连接

在 VidHub、Infuse、Moonfin 等客户端里添加服务器：

http://宿主机IP:8098

账号密码使用 Web 管理员账号，或你在 Web 里创建的用户账号。

媒体目录默认以只读方式挂载。只读模式可以正常扫描和播放，但不能在 Web 里删除媒体或写入 NFO。 如果需要测试这些功能，把 docker-compose.yml 里的 /media:ro 改为 /media:rw。

字幕

外挂字幕放在与 .strm 相同的目录，文件名保持相同 basename，例如：

Movie.strm
Movie.srt
Movie.zh.srt
Movie.ass

内嵌字幕由服务端的 ffprobe 探测，作为媒体流信息下发给播放器；Docker 镜像已包含 ffmpeg/ffprobe。

如果使用 bridge 网络且 .strm 里是 127.0.0.1，请在 .env 设置 UPSTREAM_HOST=host.docker.internal，并保留 compose 的 host-gateway 配置。

8. 常用 Docker 命令

日常

docker compose ps
docker compose logs -f --tail=100
docker compose restart
docker compose down

重新构建

docker compose build --no-cache
docker compose up -d

备份数据

先停止容器，再复制整个 data/ 目录：

docker compose down
cp -a data data.backup
docker compose up -d

9. 常见问题

打开 8098 没有响应

  • 确认容器在运行：docker compose ps；
  • 看日志：docker compose logs --tail=100；
  • 确认宿主机防火墙放行 8098，或改 .env 里的 PORT。

扫描不到媒体

  • 确认 MEDIA_PATH 指向真实目录；
  • 进入容器检查：docker compose exec emby-air ls /media；
  • Web 里添加媒体库时使用容器内路径 /media/...；
  • 标题目录名最好包含年份或 {tmdb-xxxx}，便于识别。

刮削没有内容 / TMDB 超时

  • 到「设置」检查 TMDB Key；
  • 国内网络可能需要填写 HTTP/HTTPS 代理；
  • 降低刮削速率到 8–10 再试；
  • 查看日志中的 TMDB 鉴权或超时提示。

忘记管理员密码

可以停止容器后备份并删除 data/emby.db，再重新启动初始化；这会清空数据库，请先备份。

媒体文件权限错误

Linux/NAS 上请保证 Docker 进程对媒体目录至少可读。如果要写 NFO 或删除媒体，还需要可写权限。

10. 安全建议

  • 不要把 8098 直接暴露到公网；建议放在反向代理、VPN 或内网后面；
  • 首次登录后立即修改管理员密码；
  • 不要使用 change-me 这类默认密码；
  • .env、data/、数据库和 API Key 不要发给无关人员；
  • 测试结束需要彻底清理时，删除容器和 data/ 即可，媒体文件不会被动。
